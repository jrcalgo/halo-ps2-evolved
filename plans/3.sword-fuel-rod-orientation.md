- Vista animation records are 0x60 bytes. The public MaxScript's 0x6C stride and 16-bit string IDs belong to the Xbox layout; only the 0x60 stride resolved `first_person:idle` on this map. Each idle's data reference lives in the meta area and is little-endian. Codec 3 stores node-major signed-short quaternions (stride = frame count × 8) and float translations (stride = frame count × 12). Mask popcounts matched the header counts, and the animated block ended on the mask bytes (`boundsOK`). Frame 0 is the first sample of each channel. Base-animation channels replace one another; the weapon nodes used here had only a static rotation, and the arm nodes used here had only an animated rotation.
- `camera_control` world rotation is identity and its world position is the origin, so the following Hamilton quaternions (x, y, z, w) are camera-relative. Model +x images: carbine gun `(0.998580, 0.052685, 0.007907)`; flak gun `(0.994870, 0.044827, -0.090687)`; sword handle `(0.966049, 0.206399, 0.155400)`. The carbine barrel, flak barrel, and sword blade all extend along node +x (carbine barrel child x=0.176; flak barrel child x=0.140; sword flare marker x=0.300 and bounds x to 0.362). Forearm lengths are not in the static translation channels, so absolute hand positions from the collapsed chain were not used.
- CE mesh axes, read from the retail models: gravity rifle bounds x to 0.372 with primary trigger at x=0.30; fuel rod bounds x `[-0.336, 0.237]` with primary trigger at x=0.513; energy sword flare at x=0.30 and bounds x to 0.350. All three fire or point along model +x. The port therefore applies the Halo 2 quaternion in camera space and keeps the rear origin on the existing hold.

[H2PC_TagExtraction](https://github.com/Project-Cartographer/H2PC_TagExtraction) explicitly extracts assets from Halo 2 Vista cache files, but its README labels it pre-alpha and lists legacy build dependencies. Its source maps high bits of a raw-data address to `internal`, `mainmenu`, `shared`, or `single_player_shared`; it decodes static quaternion components as signed 16-bit values normalized by 32767 and includes raw frame-data parsing. The script expects 3ds Max/MaxScript. Its Xbox record stride does not match this Vista map. The codec-3 sample order and the 32767 quaternion normalization did match the bytes checked above.
- Tag quaternions are Hamilton. A shared.map render-model node stored as `(0, -0.258819, 0, -0.965926)` has Inverse Forward/Left/Up vectors that match the columns of that matrix (error `1.3e-8`). CE cyborg finger tag quats are the Halo 2 rest quat with `w` negated; `modelconv`'s conjugate writes the Halo 2 rotation, so the port stores the samples directly.
