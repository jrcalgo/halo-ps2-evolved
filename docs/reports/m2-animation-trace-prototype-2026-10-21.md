# M2 animation touch-observer prototype

Date: 2026-10-21  
Status: opt-in instrumentation prototype compiles; runtime collection, parity, and capacity conclusions remain open.

## Change and identity

Added a fixed-capacity recorder in `submodules/halo-ce-universal/port/ps2/src/ps2_animation_trace.c` and its API in `port/ps2/include/ps2_animation_trace.h`. It records animation-datum and `tag_data` descriptor identities as integers (not adjusted payload pointers), relative offset, byte count, site, detail, and accepted/rejected state. It retains no pointer, allocates no heap, performs no I/O, and counts dropped events once the 4,096-entry table is full. The source is selected by the PS2 manifest but is inert unless `HALO_PS2_M2_ANIMATION_TRACE` is defined. `tools/hcu_ps2_closure.py --m2-animation-trace` creates a distinct build directory and reports the opt-in define.

Diagnostic-gated hooks currently cover the indexed frame accessor, indexed frame-info accessor, `animation_get_x_offsets()` bulk frame-info extent, successful uncompressed default-data cursor consumption, the three direct compressed rotation/translation/scale helper container spans, and the compressed animation schema-validation container span. Frame-data acceptance requires a valid frame index and an in-bounds computed interval; compressed helper/schema intervals share the full `animation.data` descriptor identity and compressed offset. The frame and compressed-container records describe candidate/validated extents; they do **not** mean every byte in the range was read. No phase scopes, exact compressed subfield reads, per-map unique-byte aggregation, output/serial transport, or decode-operation begin/end pairing exists yet. The recorder is also unsynchronized: before runtime use, source audit must prove these hooks execute serially on the CE game thread or replace the single table with properly owned per-thread buffers. In particular, the current recorder cannot establish concurrent leases, external cache residency, eviction safety, or an animation capacity number.

The touched CE boundaries are [`animation_get_frame_data()` and `animation_get_frame_info()`](../../submodules/halo-ce-universal/source/models/model_animation_definitions.c#L500-L568), [`animation_get_x_offsets()` and base-pose decode](../../submodules/halo-ce-universal/source/models/model_animations.c#L387-L450), [`animation_get_node_orientations()` default cursor](../../submodules/halo-ce-universal/source/models/model_animations.c#L855-L1020), the direct compressed component helpers ([rotation](../../submodules/halo-ce-universal/source/models/model_animations.c#L2160-L2280), [translation](../../submodules/halo-ce-universal/source/models/model_animations.c#L2310-L2420), [scale](../../submodules/halo-ce-universal/source/models/model_animations.c#L2450-L2570)), and the PS2-selected schema validator ([compressed animation validation](../../submodules/halo-ce-universal/port/linux/game/tag_schema_models.c#L862-L950)). The fixed recorder and event contract are in [`ps2_animation_trace.h`](../../submodules/halo-ce-universal/port/ps2/include/ps2_animation_trace.h) and [`ps2_animation_trace.c`](../../submodules/halo-ce-universal/port/ps2/src/ps2_animation_trace.c).

## Required next slices before using this for Step 8 decisions

1. Add hooks on the actual consumption boundaries for compressed header/node/default/keyframe/frame-index subranges and schema validator arrays, recording validation scans separately from runtime dereferences. Add frame/default data required-size and rejected-range events without overcounting debug `match_assert()` accessor probes; establish single-thread execution or provide separate synchronized diagnostic buffers.
2. Add explicit nested caller-phase scopes only where the last dereference is lexically bounded; include object/unit pose, biped root/frame-info, first-person tick/render, melee x-offset, device/vehicle, camera/cinematic, and sky callers. If pointer lifetime escapes a scope, record it as unknown; do not manufacture a release.
3. Add a read-only extraction/aggregation path and overflow-fatal diagnostic mode, then a deterministic fixture that invokes real CE decode paths and compares decoded poses, validator corrections, arena cursors, CE state hashes, and recorder-disabled/enabled outputs.
4. Build a dedicated diagnostic machine image with its storage explicitly budgeted and expose compact counters without per-node logging. Run only a scenario that is already admissible; current capacity audits do not show a representative d20 campaign load fits. A UI guest or synthetic host fixture is not a campaign live-set result.
5. Report distinct metrics separately: candidate ranges, confirmed source dereferences, unique byte union, operation-window overlap, and true simultaneous leased bytes (N/A until an actual lease API is implemented). Keep `TAG_SCHEMA_DATA` semantics, arena sizes, and map admission unchanged.

Halo-64 is only a source-boundary comparison here: its public accessors and the same compressed-helper bypass pattern are useful audit references, but its N64 streaming/cache design and memory cuts are not copied.
