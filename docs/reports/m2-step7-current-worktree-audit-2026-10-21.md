## Quickest aligned implementation slice

Do not start with more envelope/parser mutations: their core format rules already have good coverage. The quickest remaining semantic slice is a **retail collision + PVS/sound-value host oracle using the existing package transaction harness**, with all source files and package hashes pinned:

Link only the real CE collision source needed (`collision_bsp.c`, then `collisions.c` if the probe must include CE material and location mapping); use existing PS2 prefix/ILP32/source shims rather than copying the collision algorithm. The active `global_structure_bsp` / `global_collision_bsp` must be the objects produced by actual `ps2_cbsp_materialize()` and CE load.

Generate a small data-driven query corpus from the exact decompressed map/schema tuple: deterministic known hit and miss segments plus a swept pill; expect CE collision result, fraction, plane, surface/material/material type, breakable flag, and returned leaf indices. Ensure at least two distinct runtime material types if the source BSP provides them. Derive independent query inputs/results from source geometry/CE baseline, not hand-authored offsets; retain the map, BSP, CTAG, schema ELF, and corpus hashes. Add explicit result-to-cluster resolution for each hit.
3. Use two aligned non-overlapping host materializations (the existing Python expected image and production C output) at distinct 32-bit virtual bases. Run the same CE collision queries on each; require identical semantic tuples and every dereference to remain within that image/CTAG. Also run a small set after B000→B001→B000 in the current fixture to expose stale pointers. These are relocation-consumer semantics, not physical addresses.
4. Tighten the existing `assert_relocated_cluster_queries()` rather than duplicate it: compare exact PVS bits and sound pair values to hash-bound extracted CE source bytes, include visible/hidden clusters and unreachable sound encoding where available, and add at least one real `game_sound.c` PVS/distance branch if its runtime closure remains bounded. Keep SPU2 as a request/assertion boundary; do not stub CE sound selection.
5. Add the smallest source-backed location/environment cases present in the selected BSP: leaf/cluster transition plus a known fog-region/underwater or weather result. If the package lacks a meaningful case, select the next audited map rather than fabricating values. Preserve all BSP fields and ensure all query reads are within the declared BSP/CTAG spans.
6. Run the host suite with the package root and manifest outside the SIGSYS-restricted route when required; record current exact binary/map/source hashes. Separately keep `python3 -m pytest -q tests/test_cbsp.py tests/test_ctag_schema_walk.py` as the sandbox-safe regression. Do not label host results PCSX2/EE acceptance.
7. After Step 8 closes a lossless all-campaign owner topology, rerun the selected query corpus in the production-sized memory map and exact combined ELF in PCSX2 interpreter and recompiler, with markers proving each query family ran, physical high-water and canaries, and equal simulation outputs. Until then preserve the UI-only admission guard.
