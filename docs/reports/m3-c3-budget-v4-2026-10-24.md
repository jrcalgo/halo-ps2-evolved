# C3 memory budget v4 (2026-10-24)

Budget v4 moves 131,072 bytes (128 KiB) from the uncommitted reserve into `elf_static`, as approved by the user on 2026-10-24. The 32 MiB EE map remains 33,554,432 bytes.

The measured overage: the C3 production gameplay ELF has 2,361,604 file-backed FileSiz bytes, 2,308 bytes over the version 3 `elf_static` capacity of 2,359,296. The guest aborts at `src/stream/hcu_main.c:2362` with "ELF/boot backing exceeds EE fixed budget". The C3.11 successor link is 12,036 bytes over. The increase of 131,072 bytes covers both the current image and the successor's overage with headroom to spare.
