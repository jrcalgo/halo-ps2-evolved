# C2.5 post-load allocation inventory (2026-10-23)

## Disposition

This is a current-source allocation API/call-expression inventory, not a completed post-load allocation trace. It enumerates **211 function-body API expressions in 67 files** selected by `submodules/halo-ce-universal/port/ps2/port.json`, plus `src/stream/*.c` and the PS2 fixed-arena implementation. Top-level declarations/definitions are filtered out. The machine has no current exact-build ELF after the C2 source edits, and there is no target/workload recording proving which sites execute after map load. C2.5 therefore remains open.

The row-level source record is [m2-c2-5-postload-allocation-source-inventory-2026-10-23.json](m2-c2-5-postload-allocation-source-inventory-2026-10-23.json), regenerated with `python3 tools/audit_hcu_postload_allocations.py --output docs/reports/m2-c2-5-postload-allocation-source-inventory-2026-10-23.json`. It records source path, line, API spelling, broad owner family, release/resize notes, and an explicit unresolved phase/source-only status for every expression. The generator follows the PS2 port manifest and hashes current source against the retained compile baseline. It reports three baseline translation units whose current source hash differs: `source/ai/actors.c`, `source/interface/interface.c`, and `port/ps2/src/ps2_render.c`.

## Why no trace hook was added

A bounded ring inside `__wrap_malloc` could record events without allocating, but the return address there is often the immediate `system_malloc`/`GlobalAlloc` forwarding frame, not the original CE allocation expression. A phase variable also needs explicit transitions at load/unload/frame boundaries owned by other sources. Recording those wrapper PCs under labels such as `AI` or `renderer` would imply provenance the current interfaces do not carry. I left allocator behavior unchanged and did not add a trace that would look site-specific while actually aggregating forwarding wrappers.

The safe next trace design needs caller metadata propagated at the allocation layer (`debug_malloc` file/line and explicit IDs for direct system, pool, game-state, and arena calls), an allocation-free fixed ring, and explicit phase transitions. The trace must record allocation/free/realloc outcomes and distinguish nested pool bytes from backing arena bytes. It then needs sustained target or exact guest workloads that exercise loaded-map AI/path, bot/object churn, renderer, waves/mode changes, map unload/reload, and failure cases. Until those observations exist, the source inventory does not close C2.5.
