# M2 C2 r6, lane alloc-a (C2.5 part A)

Date: 2026-10-24. Host and EE compile evidence only; nothing ran on PCSX2 or hardware.
Build outputs: `build/m2-c2-r6-alloc-a/` and the closure run in `build/hcu-ps2-closure/all-no-bootstrap-memory/`.

## Changes

- `submodules/halo-ce-universal/source/memory/memory_pool.h`, `memory_pool.c`: `struct memory_pool_counters`
  (allocations, allocation and reallocation failures, frees, reallocations, moved reallocations, resets,
  escapes, used size, high water) lives in each pool. `memory_pool_get_counters` reads it. A move during
  reallocate is checked against the pool's extent, and an escape is counted. A free that empties the pool
  counts a reset.
- `tests/hcu_c2_alloc_a_main.c`, `tests/hcu_c2_alloc_a_shim/cseries.h`, `tests/test_hcu_c2_alloc_a.py`: the
  host driver compiles `memory_pool.c` unchanged against a small CE helper shim, then runs 100,000
  allocate/reallocate/free cycles. The Python test also reruns the two PS2 malloc tools.
- `docs/reports/m2-c2-r6-alloc-a-verdicts.json`: one verdict per inventory site in the owned files (15 sites).

## Not changed (and why)

- `source/cseries/debug_memory.c`: no PS2-specific code. `system_malloc`, `system_free` and `system_realloc`
  resolve to `GlobalAlloc`, `LocalFree` and `GlobalReAlloc` in `port/ps2/src/ps2_memory.c`, which already
  route to the compat arena after activation and count SDK calls before it. The routing is evidence, not a
  new change in this lane.
- `source/objects/objects.c`: allocation paths already call the pool and fail with FALSE on exhaustion. The
  file already carries uncommitted work from another lane, so this lane left it alone. The `objects.c:4734`
  site (`object_name_list_allocate`) is recorded as `unverified-open`.
- `port/ps2/src/ps2_memory.c`: unchanged in this lane. Its pre-activation SDK fallbacks are counted, not
  removed.
- `tools/audit_hcu_postload_allocations.py` and the inventory JSON belong to alloc-b and were not edited.

- The pool reports 62,949 failed allocations under the fixture's deliberate pressure (48 live slots in a 64
