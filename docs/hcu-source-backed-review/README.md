# HCU M0 source-backed external review

This directory is the canonical home for the M0 rooted-external review ledger, source-backed symbol reports, platform-placeholder audit, and allocation ownership evidence. The current combined-image allocation assessment is [`m0-allocation-ownership.md`](m0-allocation-ownership.md); it closes the map-range owner gap for the measured host profile but deliberately leaves production high-water and physical-placement claims open.

The report files are kept together so each ledger disposition can be audited alongside its source trace. Temporary compatibility symlinks remain at the former `docs/hcu-ps2-*` paths for existing tests and references; the actual files live here.
