# M0 Xbox debug-monitor shell-call review

**Symbols:** `DmWalkLoadedModules`, `DmWalkModuleSections`, `DmCloseModuleSections`, and `VirtualProtect`.

The only rooted callers are the local static function `fuck_code_in_the_eye` in `source/shell/shell_xbox.c`; the source calls it during Xbox shell setup, then enumerates modules and each module's sections to make the containing section read-only with `VirtualProtect`. This operation protects an Xbox executable image against writes. The PS2 image does not load or expose an Xbox Debug Monitor module table, and this protection operation is not part of the gameplay state or local-game state contract.

The PS2 edge implements the calls deliberately as an empty module enumeration: `DmWalkLoadedModules` and `DmWalkModuleSections` return `XBDM_ENDOFLIST`, while `DmCloseModuleSections` returns `XBDM_NOERR`. That preserves the CE caller's loop termination and close contract; it does not fabricate a module or section and does not turn off CE gameplay behavior. The caller's section-protection branch calling `VirtualProtect` is therefore unreachable on PS2 because there are no loaded Xbox modules; the PS2 runtime has no Win32 page-protection contract to apply to these sections. This is an excluded-proven disposition for `VirtualProtect`, tied to the separately tested state adapter, not an unreviewed blanket debug stub.

Sources: [`shell_xbox.c`](../submodules/halo-ce-universal/source/shell/shell_xbox.c#L106) and [`ps2_edge.c`](../submodules/halo-ce-universal/port/ps2/src/ps2_edge.c#L49). Test: `test_xbdm_shell_walk_terminates_on_empty_ps2_module_set` in [`test_hcu_external_review.py`](../tests/test_hcu_external_review.py) locks the caller loop and adapter return contracts; it also asserts the `VirtualProtect` ledger row is excluded-proven only because the empty enumeration makes its branch unreachable. The current combined R5900 closure compiles the owning PS2 adapter and links without undefined imports. This review does not approve neighboring filesystem, thread, or other XDK APIs.
