# M0 CTF debug-string placeholder review

`OutputDebugStringA` has exactly one rooted caller: CE's `create_the_flag` path in `source/game/game_engine_ctf.c`, through `ctf_create_flag_object`. That path creates the objective weapon, disables its automatic deactivation, then emits the fixed diagnostic literal `"created a flag"`; the object index and objective state are determined and stored by adjacent gameplay calls, not by the debugger output. The PS2 placeholder generated in `build/hcu-ps2-closure/all/ps2_platform.c` is a void no-op, so removing the output preserves the flag's gameplay state while losing only an Xbox debugger message.

Disposition: `excluded-proven` for this single symbol and this single literal-only caller. This does not approve filesystem, threading, or other debug APIs. Sources: [`game_engine_ctf.c`](../submodules/halo-ce-universal/source/game/game_engine_ctf.c#L1150) and generated [PS2 platform closure](../build/hcu-ps2-closure/all/ps2_platform.c#L85). The ledger pins the caller source hash; the test [`test_ctf_debug_string_is_diagnostic_only`](../tests/test_hcu_external_review.py) checks the fixed literal, generated no-op body, and one-caller ledger disposition. The current target closure/link still checks that the placeholder is resolved.
