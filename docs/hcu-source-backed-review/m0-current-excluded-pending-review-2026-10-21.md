## Why the network rows are not all interchangeable

`network_test_update` and `network_voice_update` are void per-frame service hooks. Their local no-op does not supply data to the tick. In contrast, `network_game_get_game` would return authoritative network match/variant state and is used by gameplay and map-transition code. Current local safety comes from the PS2-specific `network_coop_active() == FALSE` branch, not from the getter placeholder itself. The same false predicate makes the cooperative-won hook unreachable, but a future networking profile invalidates this review. Halo-64 is not a reason to remove local CE branches: its platform and game cuts differ; only the exact local PS2 adapter and caller guards matter here.

6. For network paths, instrument the local adapter to assert `network_coop_active() == FALSE`, then run local damage/friendly-fire and campaign-win fixtures proving the getter/server hook are not called and the ordinary local branches still execute. A merely successful boot is not enough.
7. For TIFF, explicitly test/document the observable contract: no file is written. Prefer a non-NULL unsupported error if the UI is meant to report failure; otherwise mark capture unsupported and never call NULL “successful screenshot export.”
8. For `debug_sound_environment`, `editor_should_exit`, telnet, UI debug path, and Xbox demos, pin the already-cited source branches and add exact-hash/manifest checks to the refreshed review suite. These tests prove only the local profile, not the feature on another platform.
