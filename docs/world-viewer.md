UV animation is omitted, alpha-replicate flags and unsupported functions fall back to the existing resolver, and this is not full Xbox shader equivalence. The source combiner table is in `submodules/halo-ce-universal/source/rasterizer/xbox/shader_transparent_chicago_preprocessor.c`.
